## 🇧🇷 Português

> **Assistente Conversacional de IA para Venda de Passagens e Suporte Rodoviário**

Chatbot inteligente para WhatsApp que cota rotas e agenda viagens de ônibus automaticamente via NLP.

### 🚀 Principais Funcionalidades
- **Cotações Automáticas 24/7**: Retorno instantâneo sobre rotas, horários e preços de passagens.
- **Processamento de Linguagem Natural**: Entendimento das dúvidas e intenções do usuário via API da OpenAI/Gemini.
- **Transbordo Humano**: Transferência automática da sessão de chat para o atendimento humano em casos complexos.
- **Gestão de Sessão**: Controle de estado de conversa leve persistido localmente via SQLite.

### 🛠️ Tecnologias
- **Base**: Node.js, Express, WebSockets, SQLite.
- **APIs / Canais**: Baileys (integração WhatsApp Web API) ou API oficial, OpenAI/Gemini.

## 🇺🇸 English

> **AI Conversational Ticketing Assistant for Bus Travel**

Intelligent WhatsApp chatbot that queries routes and books bus tickets automatically.

### 🚀 Key Features
- **24/7 Automated Quoting**: Instantly checks routes, bus schedules, and prices.
- **NLP Intent Classification**: Understands user requests naturally using Gemini/GPT APIs.
- **Human Handover**: Seamlessly transfers conversation to a support operator when needed.
- **Session Management**: Light SQLite state manager to keep active conversation context.

### 🛠️ Tech Stack
- **Base**: Node.js, Express, WebSockets, SQLite.
- **APIs / Integrations**: Baileys (WhatsApp Web API client) or Cloud API, OpenAI/Gemini.
